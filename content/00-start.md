# Start Here {#start}

Every organic molecule has a name that describes its structure exactly. Learn the rules, and a name like *4-hydroxybut-2-enal* tells you how to draw the molecule, and a drawing tells you its name. Nurses, dental hygienists, and pharmacists read these names on drug labels, safety data sheets, and lab reports every day.

The system was written by IUPAC, the International Union of Pure and Applied Chemistry, so that chemists everywhere use the same names. Its goal: **one name for each structure, and one structure for each name.**

<div class="note" markdown="1">
**Who this site is for.** This guide is written for students preparing for careers in the health professions, such as nursing and dental hygiene. It covers the naming rules and molecules you'll meet in an introductory organic and biochemistry course, and connects them to medicines and the body. If you're a chemistry, pre-med, or pre-pharmacy student heading into a full year of organic chemistry, you'll need more depth than this. See [Going Further](#more) for two good free places to go next.
</div>

<div class="warn" markdown="1">
**A note on name style.** You'll see the same molecule written two ways. The older style puts every number up front: *2-butanol*, *2-hexene*. Since 1993, IUPAC has placed each number directly in front of the part of the name it describes: *butan-2-ol*, *hex-2-ene*. The current rules (IUPAC 2013) keep this newer style. Your textbook may use the older style, and online homework platforms often mix both. Both styles describe the same molecule, and you should be able to read either. **This site uses the current style throughout.**
</div>

## How to use this site

- **Work through the sections in order.** Each one builds on the last, and they follow the order most courses teach the functional groups.
- **Keep the [priority ladder](#ladder) handy.** It's the one table you'll come back to for every molecule.
- **Read the worked examples step by step.** Open "Walk through it" to see each rule applied in order.
- **Try the practice problems before opening the answer.** Struggling for a minute is how the rules stick.
- **Look for the health connections.** They show where each functional group turns up in medicine and the body.

The numbers drawn on some structures show how the carbon chain or ring is numbered. Use the search box to find any compound or term, and the dark mode button if you study at night.
