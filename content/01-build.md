# How a Name Is Built {#build}

## The core idea

Every name starts from a **parent**: the main carbon chain or ring of the molecule, named like an alkane (*propane*, *hexane*, *cyclohexane*). Everything else on the molecule — double bonds, oxygen, nitrogen, halogens, branches — is added to the parent as a **prefix** (in front) or a **suffix** (at the end), with numbers called **locants** telling you where each piece sits.

A molecule can have only **one suffix**. When a molecule has two or more functional groups, the one highest on the priority ladder gets the suffix, and the others become prefixes.

## The priority ladder {#ladder}

The ladder has three tiers. **Tier A** groups can be a suffix. **Tier B** is the -ene and -yne endings for multiple bonds. **Tier C** groups are always prefixes, never suffixes. Within Tier A, higher on the list wins the suffix.

[[ladder]]

## Five steps for any name

1. **Find the highest-priority group** on the ladder. It will be the suffix.
2. **Choose the parent.** It must contain that group. Among chains, choose the longest. If the molecule has a ring and a chain, the ring is the parent.
3. **Number the parent** so the suffix gets the lowest number possible. If that's a tie, give the lowest numbers to the double and triple bonds, then to the prefixes.
4. **Name and number every prefix.** List them in alphabetical order. Use *di-*, *tri-*, *tetra-* for repeats, but ignore them when alphabetizing: *dimethyl* goes under *m*.
5. **Assemble the name**: prefixes, then parent, then ending, then suffix. Commas go between numbers; hyphens go between numbers and letters.

<div class="note" markdown="1">
**"Lowest numbers" means first point of difference.** Compare two possible numberings term by term, from smallest to largest. The set that is lower at the *first* place they differ wins. The set {2, 3, 6} beats {2, 4, 5}, because 3 is lower than 4, even though 6 is higher than 5.
</div>

The rest of this site applies these five steps to one family of molecules at a time.
